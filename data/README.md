# Data

Generated datasets derived from the archived entrance-exam PDFs.

## ITA phase 1

`ita_phase_1.parquet` is the canonical long-format table. Each row represents one answer alternative and contains:

- `alternative_id`: unique row identifier, for example `ITA-1F-2024-Q017-A`;
- `question_id`: question identifier shared by its alternatives and images;
- `year`, `question_number`, `subject`;
- `question_text`, `alternative`, `alternative_text`;
- `has_image`, `ocr_used`, `needs_review`, `source_pdf`, `page_start`, `page_end`.

`ita_phase_1_images.parquet` contains the one-to-many image relationship through `question_id` with `image_id`, `image_path`, source page and rendered dimensions.

`ita_phase_1.xlsx` is generated by the GitHub Actions workflow as an inspection and manual-enrichment workbook. It contains two worksheets:

- `questions`: the same long-format alternative-level data as the canonical Parquet dataset;
- `images`: the image relationship table.

The workbook uses regular worksheet ranges with autofilters and frozen headers rather than Excel structured tables, reducing compatibility issues across spreadsheet applications.

Question crops containing raster or vector graphical content are stored in `ita_phase_1_images/<year>/` and named from their `image_id`.

The Parquet datasets and images are generated by `scripts/build_ita_phase_1.py`; the Excel workbook is derived from those outputs by `scripts/export_ita_phase_1_excel.py`, called from `.github/workflows/build-ita-phase-1.yml`. Generated files should not be edited manually.
