# Data

Generated datasets derived from the archived entrance-exam PDFs.

## ITA phase 1

`ita_phase_1.parquet` is the canonical long-format table. Each row represents one answer alternative and contains:

- `alternative_id`: unique row identifier, for example `ITA-1F-2024-Q017-A`;
- `question_id`: question identifier shared by its alternatives and images;
- `year`, `question_number`, `subject`;
- `question_text`, `alternative`, `alternative_text`;
- `has_image`, `source_pdf`, `page_start`, `page_end`.

`ita_phase_1_images.parquet` contains the one-to-many image relationship through `question_id` with `image_id`, `image_path`, source page and rendered dimensions.

Question crops containing raster or vector graphical content are stored in `ita_phase_1_images/<year>/` and named from their `image_id`.

These files are generated by `scripts/build_ita_phase_1.py`; they should not be edited manually.
