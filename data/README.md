# Data

Generated datasets derived from the archived ITA entrance-exam PDFs.

## Multiple-choice questions

`ita_multiple_choice.parquet` is the canonical long-format dataset. Each row represents one answer alternative and contains:

- `alternative_id`, `question_id`;
- `year`, `exam_phase`, `question_number`, `subject`;
- `question_text`, `alternative`, `alternative_text`;
- `has_image`, `ocr_used`, `needs_review`;
- `source_pdf`, `page_start`, `page_end`.

`ita_multiple_choice_images.parquet` stores the one-to-many image relationship through `question_id`. PNG crops are stored under `ita_multiple_choice_images/<year>/`.

`ita_multiple_choice.xlsx` is an inspection workbook with `questions` and `images` worksheets.

## Essay questions

`ita_essay_questions.parquet` contains one row per open-ended question with:

- `question_id`;
- `year`, `exam_phase`, `question_number`, `subject`;
- `question_text`;
- `has_image`, `ocr_used`, `needs_review`;
- `source_pdf`, `page_start`, `page_end`.

`ita_essay_questions_images.parquet` stores the one-to-many image relationship through `question_id`. PNG crops are stored under `ita_essay_questions_images/<year>/`.

`ita_essay_questions.xlsx` is an inspection workbook with `questions` and `images` worksheets.

## Historical classification

The builder classifies the archive by question type rather than by phase. For the 2008–2018 single-phase exams, Physics, Mathematics and Chemistry questions 1–20 are treated as multiple choice and 21–30 as essay questions; English and Portuguese numbered questions are treated as multiple choice. From 2019 onward, first-phase questions are multiple choice and second-phase Physics, Mathematics and Chemistry questions are essay questions. Portuguese second-phase numbered questions are classified structurally from their A–E alternatives. Writing prompts (`redacao`) are excluded from both datasets.

All outputs are generated by `scripts/build_ita_datasets.py` through `.github/workflows/build-ita-datasets.yml`. Generated files should not be edited manually.
